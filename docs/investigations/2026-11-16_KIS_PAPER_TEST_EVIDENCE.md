### 알게 된 것

- **취소는 별도 줄로 찍힌다.** 원주문 줄은 `cncl_yn=N` 그대로이고, 새 주문번호 줄이 `orgn_odno=원주문번호`, `cncl_yn=Y` 로 생긴다.
  원주문 줄의 `cnc_cfrm_qty` 는 비어 있었다. `kis.py` 의 `do_polling()` 이 이 경우를 처리한다.
- 원주문번호가 없는 줄의 `orgn_odno` 는 빈 값이 아니라 `0000000000` 이다.
- 모의투자에서 잔고를 연달아 조회하면 `EGW00215`(원장 초당 거래건수 초과)가 온다 → 재시도 코드 목록에 추가함.
- 시장가는 1~2초 안에 체결됐다.

## 남은 관찰 (고치지 않음)

- 모의투자는 초당 호출 한도가 낮아서, 전략 실행 중 체결 조회 1번이 `EGW00201` 로 건너뛰어졌다(다음 주기에 정상 회복).
- 전략 시작 시 오늘 이미 있던 주문(다른 테스트에서 낸 것)도 엔진이 불러와 이 전략의 주문으로 처리한다(Lumibot 기본 동작).
- 로그 시각 옆 시간대 이름이 `LMT`/`JST` 로 찍히고, `pandas_market_calendars` 의 XKRX `break_start` 경고가 반복된다(표시 문제).
